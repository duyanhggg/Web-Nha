📌 Hướng dẫn lấy Cloud Name & Upload Preset trong 30 giây:

1
Đăng nhập Cloudinary và lấy Cloud Name

Mở trang cloudinary.com/console, bạn sẽ thấy ngay mục Cloud Name ở góc trên bên trái màn hình. Copy tên đó dán vào ô trên.

2
Tạo Upload Preset (Unsigned)

Bấm biểu tượng Cài đặt (Bánh răng ⚙️) ở góc dưới bên trái → chọn tab Upload → cuộn xuống mục Upload presets → bấm Add upload preset.

3
Chọn chế độ Unsigned & Lưu

Đặt tên cho Preset (ví dụ anhchinoithat), ở dòng Signing Mode chuyển thành Unsigned → bấm Save. Sau đó copy tên Preset dán vào ô bên trên là hoàn tất!
